You will only be called for mid-range quotes that passed the hard deterministic rules (not below 40% of baseline_min, not above 250% of baseline_max). Quotes outside those bounds are auto-flagged as `wildly_off` without your involvement.

    "tags": string[],          // profile tags: "specialist", "24/7", "luxury", etc.
    "description": string,     // worker description (Arabic, Arabizi, or French)
  },

  "baseline": {
    "min": number,

    "unit": "day" | "hour" | "piece" | "night" | "trip"
  }
}

OUTPUT (JSON only — no other text):
{
  "verdict": "fair" | "below_fair" | "above_fair",
  "message_darija": string,
  "confidence": number     // 0.0 - 1.0
}

RUBRIC for verdict:

- **fair**: quoted_price falls within [baseline.min × 0.8, baseline.max × 1.25] AND profile signals (specialist tag, luxury, 24/7, high experience) justify the position within that range.

- **below_fair**: quoted_price < baseline.min × 0.8. Could be a new worker establishing reputation, a budget-segment specialist, or a typo. Suggest user double-check before contracting.

- **above_fair**: quoted_price > baseline.max × 1.25. Justified ONLY if profile has at least 2 of: specialist tag, luxury tag, experience_years > 15, 24/7 tag. Otherwise flag.

LANGUAGE RULES for `message_darija`:
- Reply in idiomatic Darija. NOT MSA. NOT transliterated.
- Keep it to 1–2 short sentences.
- Tone is informational, not judgmental. "هاد الثمن قليل شوية من المعدل" not "this worker is overpricing you".
- If `verdict: "fair"`, can be brief: "الثمن مناسب للمعدل ف{city}".
- If `verdict: "below_fair"` or `"above_fair"`, mention the baseline range so the user knows what to compare against.

CONFIDENCE:
- 0.9+ : Strong signal one way (clear specialist with high price, or clear new worker with low price).
- 0.7-0.9 : Reasonable signal but profile is ambiguous.
- 0.5-0.7 : Profile is sparse; verdict is best-guess.
- < 0.5 : Don't call us; we'll route to manual review instead.
